# Portafolio QA | Casos de prueba e informes manuales

Colección de **ocho documentos** que muestran diseño de escenarios, validación de formularios y registro de resultados en pruebas funcionales.

## Resumen

Reúno casos de prueba y reportes de errores preparados para distintos ejercicios de validación. El objetivo es mostrar cómo organizo una comprobación manual y documento sus hallazgos.

## Alcance

- Diseño de casos de prueba funcionales y de caja negra.
- Clases de equivalencia, campos obligatorios y smoke testing.
- Validación de interfaz, formularios y módulos de pago.
- Documentación de discrepancias entre resultados esperados y observados.

## Herramientas

`Testing manual` · `Google Sheets/Excel` · `Jira` · `Diseño de casos` · `PDF`

## Cómo ejecutar o revisar

No hay dependencias de instalación ni código ejecutable. Abre los PDF y revisa los casos, entradas, resultados esperados y observados. Algunos documentos son ejercicios independientes; no necesariamente corresponden a una única aplicación.

## Limitaciones

La documentación conserva el formato de los ejercicios originales. Algunos casos se hicieron en entornos no disponibles actualmente; no se afirma que los errores sigan presentes. No se incluyen capturas ni enlaces privados adicionales a los publicados.
